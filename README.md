# 📡 Offline Knowledge Node (Captive Portal Text Server)

An ultra-lightweight, standalone local web server designed to serve textbooks, field documentation, and instruction boards over an offline Wi-Fi access point—**no mobile data, cellular signal, or internet connection required.**

Built to overcome heavy RF dead zones (like underground labs, areas near metro infrastructure, or field sites), this node instantly broadcasts formatted HTML, Markdown, and plain text directly to any smartphone browser upon connection.
